# v1.2.7 Factory Reset add-on correction

- Factory Reset now offers exactly two purchasable add-ons: Odor Removal ($60) and Engine Bay ($70).
- Odor Removal is no longer treated as included in Factory Reset.
- Headlight Restoration and all other add-ons are hidden for Factory Reset.
- Quote recommendations for Factory Reset now use the same rules as normal booking.
- Existing v1.2.6 normal-booking add-on support and prior quote conversion work are preserved.
