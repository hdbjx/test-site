# V107.1 Header Tone Hotfix

V107's CSS pruning removed the custom-property provider rules for the reactive shared header while leaving the consumer rules in place. The header therefore referenced undefined `--ed-header-*` values, which broke logo and control colors.

V107.1 restores the base, ink, light, brand, and menu-open tone providers from V106, preserves the native logo red token (`--color-logo-red: #d56865`) for brand tone, and adds `scripts/qa-header.mjs` to prevent this class of regression from passing prebuild again.
