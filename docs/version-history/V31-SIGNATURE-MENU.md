# V31 Signature Menu

Homepage menu redesign layered onto V30.

- Full-screen dark menu scene instead of a generic drawer.
- Five oversized primary destinations with numbered rows and contextual descriptions.
- Hover/focus changes a large real Every Detail photo preview.
- Brand-red wipe interaction uses the sampled logo red `#D56865`.
- Animated scan line and restrained orbit graphic add motion without obscuring navigation.
- Secondary destinations and booking/text actions sit in a dedicated footer rail.
- Keyboard focus continues to be trapped in the dialog and Escape returns focus to the menu trigger.
- Mobile removes the image preview and keeps the same oversized typographic hierarchy in a vertical layout.
- Reduced-motion disables decorative animation.
