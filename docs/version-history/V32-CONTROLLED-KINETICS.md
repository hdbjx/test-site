# V32 Controlled Kinetics

This pass applies the professional audit rather than adding another visual theme.

## Key changes

- Desktop homepage menu changed from full-screen takeover to a physical pull-down panel that keeps page context visible.
- Header now reacts to the active homepage scene instead of using one treatment over every background.
- Archive scene now has discrete handoff timing so the opening headline exits before the closing archive message enters.
- Student story photography gets staged opacity/scale and deliberate spacing rather than uncontrolled overlap.
- Review scene adds subtle secondary proof fragments so one quote no longer carries the entire visual concept.
- `Beyond the Reset` was structurally rebuilt into a restore -> maintain progression. The old two-card layout is removed.
- Brand red remains the sampled logo red `#D56865`.
- Existing booking, routes, service data, account, quote, and customer flows remain intact.
- Reduced-motion fallbacks are preserved.
