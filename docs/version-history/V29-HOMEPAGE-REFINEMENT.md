# V29 Homepage Refinement

Built from V28, based on rendered-page feedback.

## Major changes
- Removed the VIEW / OPEN / BOOK custom cursor entirely.
- Homepage-only header is now a centered, enlarged logo with a single MENU control.
- Homepage menu expands into the existing accessible navigation panel.
- Hero is centered and simplified into one dominant composition.
- Replaced the slow empty post-hero handoff with a short moving typographic bridge.
- Preserved the working HomeBookingFlow while tightening its surrounding hierarchy.
- Horizontal work scene now calculates exact track travel so the ending copy is fully visible.
- Built by Students is now a kinetic poster: three real images fly in, overlap the type, and separate the words.
- Review section is smaller, more reactive, and uses a rotating proof-ring motif.
- Beyond the Reset is more abstract and sculptural, with outlined marquee type, two physical panels, and a central stamp.
- Final driveway/detail-shop section intentionally kept close to V28 because it was already visually successful.

## Motion system
- Scroll controls macro scene progression.
- Pointer controls subtle local depth, tilt, hero drift, story light field, and magnetic CTAs.
- Touch devices use simplified layouts.
- Reduced-motion users receive static compositions.
- Motion calculations that require multiplication are computed in JS and written as explicit CSS values for browser reliability.
