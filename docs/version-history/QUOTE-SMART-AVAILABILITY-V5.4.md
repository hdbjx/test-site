# Quote Smart Availability V5.4

- Quote booking suggestions are diversified into Next available, Morning option, and Weekend option.
- Suggestions prefer different dates so three cards do not represent essentially the same opening.
- Falls back gracefully when a category is unavailable.
- Availability auto-scrolls into view after it loads.
- Selecting a time collapses the suggestion cards and auto-scrolls to the remaining address/confirmation step.
- Change returns to the availability choices.
- Quote-origin full booking waits for availability to load, then auto-scrolls to the time picker.
- Behavioral CRM event contract is unchanged.
