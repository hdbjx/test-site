# V61 Services Router

Rebuilt `/our-services` as a concise routing and comparison page.

## Structure
1. Clear routing hero with quote and booking paths.
2. Three core service cards organized by current vehicle condition.
3. Exact vehicle pricing comparison using the existing live pricing component.
4. Two specialty paths only: Paint Care and Detail+.
5. Concise mobile-service process.
6. Six relevant FAQs and final CTA.

## Removed
- Long educational anatomy section.
- Scroll-heavy service-depth story.
- Interior-only / exterior-only one-time service messaging.
- Redundant repeated explanations and extra conversion blocks.

## Preserved
- Central service pricing data.
- Existing booking links and tracking.
- Existing quote flow.
- Service schema / SEO metadata.
- Paint Care and Detail+ routing.
