# v96.1 live-job day-of email test

The authenticated reminder test endpoint can now render the day-of email from a real job scheduled for the current day while overriding only the recipient address.

## Test today's real job

```text
GET /api/cron/job-reminders?testEmail=olhohbobo@gmail.com&type=dayOf&useToday=1
Authorization: Bearer <CRON_SECRET>
```

Behavior:

- Reads a real non-cancelled job scheduled for today in `America/New_York`.
- Prefers the next upcoming job. If all jobs have already started, uses the most recent one.
- Loads the actual assigned crew from `job_assignments` + `profiles`.
- Sends the email only to `testEmail`.
- Does not call either claim/finalize reminder RPC.
- Does not alter the job, customer email, or reminder sent timestamps.
- Returns the job ID, customer name, scheduled start, service, vehicle, and team names in the JSON response for verification.

To force a particular job if there is more than one today, add:

```text
&jobId=<job-uuid>
```

The route returns `409` rather than sending a fake crew if the selected real job has no assigned team.
