# Every Detail V19 Studio Pass

This pass changes the objective from "technically polished" to "professionally art-directed."

## Visual direction
- Premium editorial automotive feel rather than a component-heavy startup template.
- Photography carries the brand. Decorative UI supports it instead of competing with it.
- Warm paper neutrals, near-black, and one controlled Every Detail red accent.
- Space Grotesk remains the primary display face, with a tighter and more deliberate scale.
- One rounded button language replaces mixed shadows, pills, and hard-offset button treatments.
- Cards use borders and whitespace rather than heavy offset shadows.
- Seasonal graphics remain possible, but are visually subordinate.

## Homepage changes
- Re-composed hero with stronger image treatment, narrower copy measure, calmer navigation, and integrated trust strip.
- Simplified service-selection section and removed the boxed eyebrow treatment.
- Converted work section to a dark editorial gallery so real photography becomes the visual centerpiece.
- Removed scrapbook-style image rotation from the team section.
- Simplified How It Works into a more architectural dark section.
- Unified spacing and heading behavior across homepage sections.
- Added mobile-specific composition instead of simply shrinking desktop styling.

## Technical note
The pass is implemented as a final V19 override layer in `src/app/globals.css`, preserving the existing booking logic and page structure. This makes the visual change low-risk and easy to compare or roll back while the older CSS is consolidated later.
